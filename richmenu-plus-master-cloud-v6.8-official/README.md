# リッチメニュープラス マスター版 v6.8

Vercel / GitHub にアップロードできる正式構成版です。

## 主な変更
- 保存管理を管理カード内の小さな枠ではなく、**大きいモーダル表示**へ変更
- 入口は「保存管理を開く」のみ表示
- 保存管理の中身を 4 タブに整理
  - 保存する
  - 読み込む
  - 管理する
  - 設定

## 構成
- `index.html`
- `package.json`
- `vercel.json`
- `api/`
- `apps-script/cloud-save.gs`

## 備考
- LINE反映用 API は `api/` 配下に含まれています。
- Apps Script を使う場合は、`apps-script/cloud-save.gs` の内容を Google Apps Script に貼り付けて、Web アプリとして再デプロイしてください。
- 既存のクラウド保存・重複整理・シート整理・クラウド削除などの機能はそのまま残しています。


## v6.8.1 修正

- 確認用モードの案内文を表示しないように修正しました。
- GitHub / Vercel に上げる正式版として使える表示に整えています。

## v6.9 追加

- 保存管理モーダルに「紐づけ中のスプレッドシート」表示を追加しました。
- 管理タブと設定タブから、紐づけ中のGoogleスプレッドシートURLを確認できます。
- 「紐づけシートを表示」「シートを開く」「URLをコピー」を追加しました。
- 使い方が分かる説明欄を追加しました。
- LINE反映時に、トークン保存の通知が先に出ないように調整しました。
