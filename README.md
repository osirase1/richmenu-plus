# リッチメニュープラス マスター版 v6.9.8
Vercel / GitHub にアップロードできる正式構成版です。


## v6.9.8 セキュリティ・安定性修正

- **画像仕様は変更していません。** Large 2500×1686 / Compact 2500×843 の既存仕様を維持します。
- v6.9.7相当の反映状態チェック（デフォルト / 個別リンク richMenuId）は既存実装を維持します。
- 未保存の変更がある場合、自動保存設定のON/OFFに関係なくページ離脱警告を出すよう修正しました。
- LINE反映前に、メニュー名・チャットバーテキスト・エリア数・エイリアスID・エリア範囲・アクション設定を検証します。
- クラウド保存データからLINEチャネルアクセストークンを除外しました。JSONバックアップなど既存のローカル用途は従来仕様を維持します。
- Apps Script用コードにブラウザごとのクラウドアクセスキーを自動埋め込みし、クラウド操作時に照合するようにしました。
- `package.json` の `check` は、`api/` が不足している不完全な構成を明示的にエラーとして検出します。
- ローカル起動は `npx vercel dev` を使うようにし、Vercel CLIのグローバルインストール前提を外しました。
- 保存データ内部のバージョン表記を `6.9.8-security-reliability` に更新しました。

> 重要：既に古いApps Scriptコードをデプロイ済みの場合は、「コードをコピー」で最新版をコピーし、Apps Scriptの「デプロイを管理」から**新バージョン**として再デプロイしてください。新しいアクセスキー保護は再デプロイ後に有効になります。

## 主な変更
- 保存管理を管理カード内の小さな枠ではなく、**大きいモーダル表示**へ変更
- 入口は「保存管理を開く」のみ表示
- 保存管理の中身を 3 タブに整理

  - クラウド設定

## 備考
- LINE反映用 API は `api/` 配下に含まれています。
- Apps Scriptのクラウド保存コードはアクセスキーをブラウザごとに埋め込むため、固定の `cloud-save.gs` は同梱せず、アプリ内の「コードをコピー」から生成してください。
- Apps Script を使う場合は、アプリ内の「コードをコピー」で生成されるコードを Google Apps Script に貼り付け、Webアプリとしてデプロイしてください。v6.9.8ではクラウドアクセスキーをコードへ自動埋め込みするため、アプリ内で生成したコードを正として使用します。
- 既存のクラウド保存・重複整理・シート整理・クラウド削除などの機能はそのまま残しています。
